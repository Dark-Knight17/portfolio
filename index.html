Keystroke Dynamics Platform

My defended Final Year Project: continuous authentication for online programming assessments, using keystroke typing rhythm instead of a one-time login check. The pipeline collects keystroke data through an API and stores it in PostgreSQL, then scores it against three deep learning models trained in Google Colab. A Transformer encoder came out on top (AUC 0.791, EER 0.227) and is the one deployed for live authentication in the demo.

Full-stack: FastAPI backend, React 19 / TypeScript frontend, trained and evaluated across three model architectures before selecting the best performer.
